# 模板框架指南

## 构建与调试

构建和运行见[说明](../README.md)。`_DEBUG` 检查框架的单写和接线；保留标准 `assert` 时还需避免 Release 的 `NDEBUG`。

## 周期边界

- `Wire` 只接线一次，本拍首次读取时求值，`sync()` 清缓存。
- `Register` 读取旧值，使用 `<=` 写下一值，每拍最多写一次。
- 先执行所有模块的 `work()`，再统一 `sync()`。不要用调用顺序做跨模块旁路。
- 输入接到模块实例上；组合仲裁不因封装模块而增加寄存边界。
